Introduction to Python: Mobile and Web application development

Course Map & Weekly Roadmap
Week / Unit	 Theme	Key Focus Areas

Unit 6	    Capstone App – Build, Test & Refine	Application architecture, integration testing, error logging, UI polishing	 

Unit 7	   Capstone Presentation & Assessment	Live/recorded project demonstration, technical write-up, peer evaluations
